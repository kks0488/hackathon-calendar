# Hackathon Calendar

해커톤 일정 자동 구독 캘린더

## 캘린더 구독 URL

```
https://raw.githubusercontent.com/kks0488/hackathon-calendar/main/hackathon-calendar.ics
```

### Apple Calendar 구독
1. 설정 > 캘린더 > 계정 > 캘린더 구독 추가
2. 위 URL 붙여넣기
3. 자동 새로고침: 매일

### Google Calendar 구독
1. calendar.google.com > 다른 캘린더 + > URL로 추가
2. 위 URL 붙여넣기
